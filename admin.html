Sign in

This desk saves changes as commits to the site's GitHub repo, so it needs your personal access token. It's stored only in this browser.

Make one at github.com → Settings → Developer settings → Fine-grained tokens: access to only this repository, with Contents set to Read and write. Pick a long expiration; you'll paste a fresh one when it lapses.

Ratings

Click the right half of a star for a whole number, the left half for a half (left side of the 4th star = 3.5). ✕ clears. Changes save as commits a moment after you stop clicking — watch the “saved ✓” up top.

Recommendations

Recommendations live in the Google Sheet, not in data.json — the sheet is the admin surface. Delete a row to remove one, edit a cell to revise, type a new row to add. The public page picks up changes within a few minutes.

Members

Deactivating hides a member from the public site entirely — their column, their row, and their effect on averages. Nothing is deleted: reactivate and it all comes back.
